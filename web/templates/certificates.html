How to read the verdict

  • ok — the certificate file was read and parsed just now, and has more than the window above left.
  • soon — read and parsed just now, and inside the window above. A renewing Comb will attempt renewal on its own tick; one that is not renewing needs an operator.
  • expired — read and parsed just now, and its own validity has already ended. The serving service is presenting a certificate that clients will reject.
  • unknown — the check did not complete: the file was missing, unreadable, or would not parse. This is neither healthy nor expired. It is also not a statement about this Comb's health or its quorum membership — a bad serving certificate and an unreachable Comb are separate facts, and this verdict can only ever be the first one.

“Recorded expiry” above is this Comb's own inventory copy, written when the certificate was installed. It is shown as context, never as the verdict: it records what a file was when Apiary put it there, and the verdict column is the only thing on this page that has read the file since.
