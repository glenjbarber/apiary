Hive loss

Scope of this edition

This edition covers exactly one scenario: the loss of a single named hive, including the special case where that hive currently holds raft leadership. It is generated fresh on every request from live cluster state - it is not derived from a persisted "Flight Plan" (that mechanism does not exist yet in Apiary).

Not covered by this or any current edition: management-network (control-plane) failure - distinct from the already-built managed tenant-network failure simulator; total control-plane loss (every raft voter gone at once - see raftd -export's own config-archive mechanism instead); rebuilding from surviving storage; and the online Guided Recovery Mode, both of which depend on a Flight Plan execution engine that does not exist yet.
