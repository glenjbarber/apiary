Network interface

Which physical interface VLAN tagging and outbound NAT (ADR-0048) use on this node, and which resolver Apiary advertises to Cells. Changes here take effect the next time this node's managerd restarts, not live. Blank NAT uplink means use Uplink. Blank DNS means use the startup flag value, if one was supplied. Interface choices are discovered from this Hive; a saved interface that is no longer present is retained as an unavailable choice so it can be cleared safely.

{{template "nodeconfig_panel" .}}

Resource scope paths

Where this Hive looks for its own existing VM storage, jail images, and installer images. Write-once through this page: changing one of these after real resources already exist under the old value does not move them - it just makes the reconciler stop seeing them, silently orphaning real VMs, jails, or ISOs. Once a value below is set, it can only be changed by editing the underlying rc.conf flag directly and restarting.

Bhyve / VM provisioning

Blank boot ROM disables bhyve provisioning on this node entirely; blank bridge disables VM networking. Disk size and reconcile interval only affect newly created VMs/ticks, never an existing one.

{{template "bhyve_config_panel" .}}

HAST-backed disk replication

Enables HAST support on this node (ADR-0026) - needed on both a replicated VM's owning node and its replica node, regardless of bhyve support. Requires a real, patched hastd.

{{template "hast_panel" .}}

Jail provisioning

Controls whether this Hive provisions jails assigned to it. If a jail row says provisioning is disabled on the owning node, enable it here on that owning Hive.

Peer-to-peer forwarding

Used when this node forwards a raft write/read to the leader's managerd (ADR-0029/ADR-0035), or dials another Hive for a cross-Hive console/serial-log request. The peer API key is write-only - it is never shown once saved, only whether one is set.

{{template "peer_forwarding_panel" .}}

TLS

Certificate/key paths for this node's own external gRPC API (managerd) - not the certificate content itself, which stays on disk. Leave both blank to serve plaintext.

Automated Assumption Checks tuning

Timing and retention for the continuously re-evaluated assumption checks (ADR-0055). Pure tuning knobs - safe to change any time.

{{template "assumption_tuning_panel" .}}

Internal security

Shared secret this node presents to raftd's own internal socket (ADR-0033) - must match raftd's own -internal-token. Write-only, same as the peer API key above.

Apiary services

Status is local to this Hive. Restarting apiary_managerd applies saved Machine settings such as jail provisioning. Apiary does not change rc.conf here.

VM firewall overrides

Temporarily suspend enforcement of a VM's firewall rules (everything allowed) without discarding them - useful for troubleshooting connectivity. Only VMs assigned to this node are shown.

{{template "machine_vms_panel" .}}

Cloudflare Tunnel exposure

Lets a Cell's own HTTP service be reached at a public hostname through a Cloudflare Tunnel, without opening any inbound port on this Hive - see docs/adr/0063-cloudflare-tunnel-exposure-v1.md in the repository. Set per-Cell on each VM's own detail page, once configured here.

{{if .CloudflareConfigured}}

configured This Hive's managerd has Cloudflare Tunnel exposure enabled.

{{else}}

not configured This Hive's managerd has no Cloudflare Tunnel exposure configured - Cells on this Hive cannot be exposed until it is.

One-time setup per Hive, done by hand (this project never automates it):

  1. The domain's DNS must already be managed by Cloudflare (its nameservers point at Cloudflare).
  2. Install cloudflared on this Hive, then run cloudflared tunnel login and cloudflared tunnel create <hive-name> once - this produces a tunnel id and a credentials JSON file.
  3. Create a Cloudflare API token scoped to Zone:DNS:Edit only (never Tunnel:Edit or account-level) for the zone Apiary will manage CNAME records in, and save it to a file only this host can read.
  4. Fill in the token file's path plus the zone/tunnel id and credentials file path below (or set the matching -cloudflare-* flags directly in rc.conf), then restart apiary_managerd.

Once set, Apiary automatically creates/updates the DNS CNAME record for each exposed Cell - no manual DNS editing per Cell.

{{end}}
