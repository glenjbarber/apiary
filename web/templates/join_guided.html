Step 1: Generate first code & fingerprints

On the joining Comb, run:
apiaryctl join-introduce

This will display a first code and a set of fingerprints. Keep this screen visible.

Step 2: Enter first code & fingerprints

Enter the first code and fingerprints exactly as shown on the joining Comb's screen.

Step 3: Prepare joining Comb

On the joining Comb, run:
apiaryctl join-prepare

This will wipe the raft state and restart the Comb with -await-join.

Step 4: Poll for second PIN

The wizard will now poll the joining Comb for the second PIN. Keep the joining Comb's screen visible to read the PIN when it appears.
