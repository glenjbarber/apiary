Updating

{{/* v1's limits are stated on the page itself rather than only in the source. An operator deciding whether to use this feature must be able to see, at the point of decision, that there is no scheduled upgrade, no removal, and no base-system update. */}}
  • Reading this page requires no privilege and changes nothing on the host.
  • Nothing on this page is ever updated automatically. There is no schedule, no timer, and no unattended upgrade path.
  • This version never removes a package, and never runs pkg update or pkg upgrade on its own.
  • This version does not perform base system updates. A base update is a reboot, and must be scheduled deliberately outside this workflow.
  • Applying an update requires a separately previewed plan, an exact typed confirmation phrase, root, and a fresh inventory read that proves the change landed. An outcome that cannot be established afterwards is recorded as unknown — never as success.
